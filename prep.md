# Introduction
Before combining the GFSI data with the FAO data, we must first compile each dataset separately and do some work to make them compatible. I break this down into 3 steps:
1. Combine GFSI data exports into a single file ([GFSI.py](https://github.com/milleroztn/Food-Security-Index/blob/main/prep/GFSI.py))
2. Download, Reshape, and Combine data from faostat server for several types of variables ([reshapeFAO.py](https://github.com/milleroztn/Food-Security-Index/blob/main/prep/reshapeFAO.py))
3. Combine GFSI with FAO data ([combine.py](https://github.com/milleroztn/Food-Security-Index/blob/main/prep/combine.py))

The `raw data` subfolder contains both the GFSI exports and some of the FAOstat datasets that were downloaded manually from FAO. The processed datasets are saved in the `data` folder for use in analysis.

The final datasets are organized in long form by year. Different versions of the data include:

## GFSI:
- [gfsi_all.csv](https://github.com/milleroztn/Food-Security-Index/blob/main/data/gfsi_all.csv): all of the data from the GFSI exports, including all 92 measures and sub-measures
- [gfsi_main5.csv](https://github.com/milleroztn/Food-Security-Index/blob/main/data/gfsi_main5.csv): a slightly restricted dataset that only includes the overall Food Security Index value and each of the four main components: Affordability, Availability, Quality, and Adaptability
- [gfsi_r.csv](https://github.com/milleroztn/Food-Security-Index/blob/main/data/gfsi_r.csv): summary statistics for the Food Security Index and four components for the entire Sub-Saharan Africa region
- [gfsi_SSA.csv](https://github.com/milleroztn/Food-Security-Index/blob/main/data/gfsi_SSA.csv): Food Security Index and four components for each available country in Sub-Saharan Africa, by country

## FAO
- [FAO_r.csv](https://github.com/milleroztn/Food-Security-Index/blob/main/data/FAO_r.csv): All available and relevant FAO variables, for each available region (including Africa, Americas, Asia, Europe, Northern Africa, Northern America, Oceania, Sub-Saharan Africa, and the entire World)
- [FAO_SSA.csv](https://github.com/milleroztn/Food-Security-Index/blob/main/data/FAO_SSA.csv): All available and relevant FAO variables, for each country in Sub-Saharan Africa

# GFSI prep

The [GFSI.py](https://github.com/milleroztn/Food-Security-Index/blob/main/prep/GFSI.py) script imports and combines several sheets that were manually extracted from the GFSI (Global Food Security Index) workbook (available from [Economist Impact](https://impact.economist.com/sustainability/project/food-security-index/download-the-index)). The GFSI is an index developed by Economist Impact and Corteva Agriscience. It includes 68 unique measures of various aspects of food security in four main categories: Affordability, Availability, Quality, and Adaptability. Many variables are proprietary measures generated by the Economist Intelligence Unit. These measures are weighted according to the opinions of various experts and combined into a total of 92 measures and sub-measures, including a single overall index of food security. 

The GFSI is available for years 2012-2022 and includes data from countries around the world, including 26 countries in sub-Saharan Africa. Each exported sheet contains all 92 measures and sub-measures for these 26 sub-Saharan African countries as well as aggregate measures (mean, median, max, and min) for the entire sub-Saharan Africa region.
